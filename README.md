# Tic-Tac-Toe

A browser-based Tic-Tac-Toe game built with **HTML, CSS, and JavaScript** as part of **The Odin Project** curriculum. This project focuses on writing modular JavaScript using **factory functions** and the **module pattern (IIFE)** while keeping game logic separate from the user interface.

---

## Live Demo

👉 **[View the project here](https://ourhouchmohamed97.github.io/tic-tac-toe/)**


## Features

- 🎮 Two-player gameplay
- ✍️ Custom player names
- ❌⭕ Turn-based game logic
- 🏆 Automatic win detection
- 🤝 Tie detection
- 🚫 Prevents moves on occupied cells
- 🔄 Restart game functionality
- 📱 Clean and responsive interface

## Built With

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Factory Functions
- Module Pattern (IIFE)

## Learning Objectives

This project demonstrates:

- Organizing code into reusable modules
- Using factory functions instead of classes
- Encapsulating state with IIFEs
- Separating application logic from DOM manipulation
- Managing game state in JavaScript
